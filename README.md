# The Virtual Tower

Portal de puzzles digitais em HTML/CSS/JavaScript — cada "andar" é um desafio diferente (o primeiro envolve esteganografia).

## Como jogar

1. Baixe/clone o repositório.
2. Abra `index.html` no navegador.
3. Avance pelos andares (`floor1.html`, `magiciansdomain.html`, ...) resolvendo cada puzzle.

Dica do primeiro andar: **esteganografia** — a resposta está escondida dentro de `Tower.jpeg`, não só no texto da página.

## Stack

HTML5, CSS3, JavaScript vanilla.
